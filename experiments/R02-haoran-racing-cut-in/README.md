## 实际策略改动

R07 超车检查已预测前后车相对距离，但侧向通行主要检查对手当前的位置。本次用连续合法观察中的 `self.n + rival.dn` 估计对手在道路坐标中的横向速度，补偿自己的换线。缺首帧、样本间隔超过 0.25 秒、对手消失后重现或阶段重置时，不沿用旧速度。

在原有 2 秒超车预测窗内，检查对手从当前位置到线性预测位置扫过的横向区间；预计进入目标/换线走廊时提前拒绝。正在超越的前车若预计挤入目标线，也会提前取消或选择另一条可用线。原有当前占位否决保留。

2 秒沿用现有长向预测窗口，横向速度裁剪为 ±4 m/s；它们是策略设计选择，不是拟合出的平台物理参数。线性预测可能过于保守，仍可能影响超车成功率或完赛时间，需本人日志与正式比赛验证。
