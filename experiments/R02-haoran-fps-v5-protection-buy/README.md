## 单项改动

只在 `Candidate` 新增 `buy` 覆盖方法，现有瞄准、导航、恢复、搜点和目标优先代码不改，`starter_player.py`、`waypoint_nav.py` 与第四版逐字节一致。购买顺序：

1. 没有主武器且买得起：进攻AK47（2700），防守M4A1（2900）。
2. 护甲低于50且现金至少650：补护甲。
3. 已有100护甲、没有头盔、现金至少350：升级头盔。
4. 防守、没有拆包器且现金至少400：最后购买拆包器。

仅在buy阶段且存活时购买；已拥有的物品不重复买。按地图/回合/攻守记录当前购买请求；收到本人上次购买的明确失败回执后，本回合跳过该物品，下一回合重置；非购买失败回执不算购买失败。不修改现金或装备，实际结果由平台观察更新。

价格依据为已有规则基线中的枪/护甲/拆包器价格和Borgo成功购买事件：helmet有350升级与1000组合两档。本轮保守地**只在满护甲时请求350升级**，不将残甲或无甲角色视为可按350获得完整头部防护，也没有实现1000组合购买或全队经济最优化。

防守800手枪局现在优先护甲，之后剩150，不买拆包器。这是明确的生存/拆包能力取舍；它可能提高抗伤害能力，也可能使团队少一个拆包器。没有使用不可见的队友装备，也没有假定队友一定有拆包器。主武器优先可能在部分预算下仍无钱补甲，留给后续单独评估。
