## 本轮策略与边界

仅改 `strategies/fps/agent.py`，保留原 `starter_player.py`、`waypoint_nav.py`、进攻掉包回收和正常防守。

1. 仅在存活、防守、live、炸弹已安放且坐标未知时，从合法地图中的公开包点开始搜索，先选择离自己最近的点。
2. 进入点中心 1 m 后，停止移动、朝地面附近转动视角，连续检查 150 tick（2.5 秒）。这是首轮设计参数，不能保证看见整个包区；没有发现仅表示本轮搜索未找到，不能认定此点无炸弹。
3. 检查后仍没有坐标，就去另一公开包点；全部检查过则继续轮巡。失明、离地、离开半径、回调间隔或交战会中断连续检查。地图、回合、引信和任务状态变化会清理相应状态。
4. 合法观察一旦提供包位，即交回原来的追踪/拆除逻辑。原来的可见敌人交战、近距离拆除和安放优先级保持。防守方安放后的非交战赶路由慢走改为跑动，以应对 40 秒限时；不新增冲刺。

搜索只依赖本人位置/状态、公开地图包点、公开安放状态及引信，不使用 seed、对手隐藏状态、事件中的实际包位或其他席位日志。代价是环视和转场可能耗时或暴露位置，仍须平台比赛验证。
