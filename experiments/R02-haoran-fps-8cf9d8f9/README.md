下述回合号为人类使用的 1 起始，JSON 的 round_index 为 0 起始。

第 **10 回合**也出现类似问题：401 次交战观察中 398 次紧接不可见帧，仅 3 次连续交战；请求和实际开火各 1 次。这个回合本队赢了，说明问题不只存在于败局。上述现象不能用“弹匣耗尽”解释。

**下一项单独候选计划**：给最近可见目标一个很短的瞄准/姿态保持期，短暂丢失视野时不立刻转回导航或守点视角；不对隐藏目标继续开火。仅使用本人刚看到的位置和 tick，超时退出；回合/死亡/购买阶段重置，保留拆包和下包优先级。先验证可见性间歇场景不会反复转回固定看点，再做完整日志回归、打包与平台验证。保持期长短是待检查参数，目前没有实现或实战收益。

不先调大转向力度：对本场 3-tick 间隔、无开火且 HP 不变的观察，yaw 位移/上一帧 applied yaw_rate 的中位数为 0.15（14,565 个样本），pitch 比为 0.1（2,942 个样本），与现有控制分母一致。该观察性检查不是独立引擎契约；主要证据仍是逐帧交战/守点反向切换。
