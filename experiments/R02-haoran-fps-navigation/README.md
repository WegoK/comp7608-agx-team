## 问题、假设与实现

R08 的 `_detour` 对全部导航节点按距离排序，再从中选择最近的合格挂接点。实际只使用排序后的一个节点，可用一次扫描同时选出全局最近节点和合格最近节点，去掉全图排序的时间与列表分配。

实现保留高度与半径边界、失败节点/边的有效期、当前受阻目标的排除、目标节点选择及后续 A*。距离相等时只用严格小于更新，保留原始节点插入顺序，与 Python 稳定排序的选择一致。

最初曾以课件 starter 尝试坡面容差和持续脱困；读取最新交接说明与小组现有实验后，未采用这份草稿，改为在 R08 上做本次局部优化。先前草稿的 14 组程序检查与 5,000 次调用不计作本候选证据。没有复制整份工具包策略覆盖 R08。
