## 把范围限定在一个决策

原策略允许干地在即将制动时提前准备独立车道，但湿地的该入口被限制。新增候选只允许湿地在以下条件下**提出**两侧车道比较，不能直接强行换线：

- 正赛第二圈起，GGV 已启用；前车非汇入车辆，间距严格在 90–180 m；本车比前车快 >2 m/s。
- 湿度至少 0.5，无防守、进站、滑胎；航向误差不超过 0.1 rad，当前目标与执行偏移差不超过 0.25 m、跟踪误差不超过 0.4 m。
- 前方 90/180/300/400 m 的原速度计划提示将明显制动。原有短期可追上判断不满足时，才走新增入口。

两侧仍必须通过原来未来 0.7/1.4/2.2 秒道路区间的交集约束和风险否决。湿地不使用干地“超出交集后再逐点投影”的放行。用已有的四秒进度/紧急停车模型比较原线与旁线，旁线 utility 必须高出原线 0.05 才可承诺。之后沿用原有转向、物理包络、避碰、退让、退出和停滞恢复。

90–180 m、误差门槛和 0.05 余量是本轮受限设计，未拟合最优值。源码仅改 `approach_conflict` 和 `tactics`；感知、抓地、紧急停车、转向、油门/刹车入口、发车逻辑、进站、设计、权重、另外两赛道前视驾驶器均保持原样。这是一个选线入口实验，不同时修改这些安全公式。
