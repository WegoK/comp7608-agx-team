## 做一轮实验

1. 从对应比赛的源码建立个人分支，选一个问题，填写[实验记录](https://github.com/WegoK/comp7608-agx-team/blob/codex/r01-local-evaluation/experiments/TEMPLATE.md)。
2. 对照[本地历史策略](https://github.com/WegoK/comp7608-agx-team/tree/codex/r01-local-evaluation/strategies/local/)测试改动，记录同条件下的差值。正式上场后，把赛果补到对应的版本记录。
3. 把结论写入[小组报告](https://github.com/WegoK/comp7608-agx-team/blob/codex/r01-local-evaluation/report/REPORT.md)，提交合并请求，请另一位组员审阅。
